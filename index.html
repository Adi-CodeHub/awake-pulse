FAQ

Questions, answered

Quick answers about what AwakePulse does and how to use it.

What is AwakePulse?
AwakePulse is a lightweight Windows utility that helps keep your PC from going to sleep. You can also choose to keep the display on, and set an optional auto-stop timer.
How do I download AwakePulse?
Click any Download for Windows button on this page. It downloads AwakePulse.exe directly from the project's GitHub release. Run the downloaded file to start the app.
What does “Keep Display / Screen ON” do?
When it is ticked, AwakePulse also asks Windows not to turn the screen off, not just to avoid sleep. Untick it if you only want the PC itself to stay awake.
How does the auto-stop timer work?
Choose a duration, or select Indefinite to keep sleep prevention on until you turn it off yourself. When the chosen time is reached, sleep prevention stops.
How do I turn sleep prevention off?
Use the Sleep Prevention switch in the app to turn it off, or let the auto-stop timer end it for you.
Which versions of Windows does AwakePulse support?
Specific Windows versions are not listed yet. Please check the project's GitHub page for the latest details before downloading.
